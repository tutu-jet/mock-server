有多个 IP 是因为电脑有多张网卡（公司网 / Wi-Fi / 热点 / 虚拟网卡）。 手机填哪个要看哪个能连通——先用默认网卡那个，连不上再换下一个（见步骤 0）。

如何自己查电脑 IP

上面探测的 IP 不准时，自己查最可靠：

  • macOS：终端执行 ipconfig getifaddr en0（Wi-Fi 通常是 en0；接网线或用热点可能是 en1）。或「系统设置 → 网络 → 当前连接 → 详细信息 → TCP/IP」看 IP 地址。
  • Windows：ipconfig，找当前连接那块网卡的「IPv4 地址」。

记住：手机要连的是电脑在当前 Wi-Fi 下的局域网 IP（一般是 192.168.x.x 或 10.x.x.x），不是公网 IP。

前置条件

  • 手机和电脑连同一个 Wi-Fi（最稳的是：电脑连手机开的热点，几乎不会被隔离）。
  • 电脑防火墙允许 {{ proxy_port }} 入站（macOS 默认允许局域网；Windows 首次会弹确认框，要点「允许」）。
  • mock-server 已 python main.py 启动，控制台无报错。

步骤 0 · 先确认手机能连到电脑（最关键）

这一步能挡掉 90% 的「mitm.it 打不开」。还没配代理，只测网络通不通：

  1. 手机浏览器直接访问 http://<电脑IP>:{{ ui_port }}，例如 http://{{ lan_ip }}:{{ ui_port }}。
  2. 能打开这个帮助页 → 网络通，继续步骤 1。
  3. 打不开 → 换上面「当前信息」里的其它候选 IP 逐个试。全都打不开，多半是公司 Wi-Fi 客户端隔离（手机电脑互不可见）——改用手机热点：电脑连手机热点，再重查电脑 IP。

注意是 {{ ui_port }}（UI 端口、直连），不是代理端口 {{ proxy_port }}。

步骤 1 · 设置手机 Wi-Fi 代理

  1. 「设置 → Wi-Fi」，长按当前已连接的 Wi-Fi，点「修改网络」。
  2. 展开「高级选项」，「代理」改为 手动。
  3. 主机名填步骤 0 里验证过能连通的那个 IP，端口填 {{ proxy_port }}，保存。

各厂商位置略有差异（MIUI/HyperOS、ColorOS、OneUI），都在 Wi-Fi 详情里，搜「代理」即可。

步骤 2 · 安装 mitmproxy 根证书（HTTPS 必装）

  1. 手机浏览器打开 http://mitm.it（务必用 http，不要 https）。能看到下载页，才说明代理真的通了。
  2. 点 Android 那栏下载 mitmproxy-ca-cert.cer。
  3. 「设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书」，选刚下载的文件，取名保存。

若 mitm.it 显示「traffic is not passing through mitmproxy」或打不开：代理没生效，回步骤 1 核对 IP/端口；若步骤 0 本就连不上，先解决步骤 0。

步骤 3 · 抓 App 的 HTTPS（Android 7+）

Android 7 起，App 默认不信任用户安装的 CA，只有以下情况能抓到 App（浏览器流量不受此限，装好证书即可抓）：

  • App 自己声明信任用户证书：在 network_security_config.xml 加 <certificates src="user"/>（建议只在 debug 构建加），重新打包安装。
  • 系统证书：root 过的机器/模拟器，把证书放到 /system/etc/security/cacerts/。
  • frida / objection：运行时绕过 SSL Pinning。

验证

  1. 手机访问任意 HTTP 站点，如 http://example.com。
  2. 回到左侧「流量」页，应立刻看到对应请求。
  3. 在「规则」页启用一条规则（或新建，pattern 用 https://example.com/*），再访问就会被 mock。

常见问题

mitm.it 打不开
先做步骤 0：手机连不到电脑（公司 Wi-Fi 隔离 / IP 填错 / 不同网段），这时 mitm.it 永远打不开。能连通后再查代理是否设为「手动」且 IP、端口正确。另外必须用 http://mitm.it，不能带 s。
手机打不开任何网页
代理 IP/端口写错、电脑没开 mock-server、或防火墙挡了 {{ proxy_port }}。先把代理关掉确认手机能正常上网，再回步骤 0。
HTTP 能抓，HTTPS 全是错
根证书没装或没被信任。重做步骤 2，装到「CA 证书」而不是「VPN 和应用证书」。
App 抓不到（浏览器能抓）
该 App 不信任用户证书，见步骤 3。
多个 IP 不知道填哪个
按「当前信息」里从上到下逐个用步骤 0 试。实在不行用手机热点（电脑连手机热点），最省心。
电脑 IP 总是变
给电脑配静态 IP，或在路由器后台按 MAC 绑定固定 IP。
