手机接入

先验证网络，再设置代理和证书。按顺序展开下方步骤。

开始前检查{{ disclosure_icon() }}
  • 手机和电脑连接同一个 Wi-Fi；公司网络隔离时，可让电脑连接手机热点。
  • 电脑防火墙允许 {{ proxy_port }} 入站。Windows 首次弹窗时选择「允许」。
  • mock-server 已通过 python main.py 启动，控制台无报错。
步骤 0 · 验证网络连通{{ disclosure_icon() }}

先不设置代理，用手机浏览器访问电脑的 UI 地址：

http://{{ lan_ip }}:{{ ui_port }}
  • 能打开帮助页：网络已连通，继续步骤 1。
  • 打不开：换「候选 IP」中的地址逐个尝试。仍无法连接时，检查 Wi-Fi 隔离、防火墙或改用手机热点。

这里使用 UI 端口 {{ ui_port }}，不是代理端口 {{ proxy_port }}。通用地址为 http://<电脑 IP>:{{ ui_port }}。

步骤 1 · 设置 Wi-Fi 代理{{ disclosure_icon() }}
  1. 进入手机「设置 → Wi-Fi」，打开当前网络的详情或「修改网络」。
  2. 展开「高级选项」，将「代理」设为手动。
  3. 主机名填写步骤 0 中已验证可连接的 IP，端口填 {{ proxy_port }}，保存。

MIUI/HyperOS、ColorOS、OneUI 的入口不同，可在 Wi-Fi 详情中搜索「代理」。

步骤 2 · 安装 HTTPS 证书{{ disclosure_icon() }}
  1. 手机浏览器访问 http://mitm.it，必须使用 http，不要使用 https。能看到下载页，才说明代理已连通。
  2. 点击 Android 下载 mitmproxy-ca-cert.cer。
  3. 进入「设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书」，选择下载的文件，命名并保存。

若页面提示「traffic is not passing through mitmproxy」，回步骤 1 核对代理 IP 和端口。若步骤 0 也无法连接，先解决网络问题。

步骤 3 · 配置 App 的 HTTPS 信任{{ disclosure_icon() }}

Android 7+ 的 App 默认不信任用户安装的 CA。浏览器可以抓包，但 App 需要满足以下条件之一：

  • App 声明信任用户证书：在 network_security_config.xml 中加入 <certificates src="user"/>，建议仅用于 debug 构建，重新打包安装。
  • 系统证书：在 root 设备或模拟器中，将证书放入 /system/etc/security/cacerts/。
  • frida / objection：运行时绕过 SSL Pinning。
验证抓包和 Mock{{ disclosure_icon() }}
  1. 手机访问 HTTP 站点，如 http://example.com。
  2. 打开顶部「流量」页，确认出现对应请求。
  3. 在「规则」页启用规则（或新建 URL pattern 为 https://example.com/* 的规则），确保整体 Mock 已开启，再访问匹配地址验证响应。

手动查询电脑 IP{{ disclosure_icon() }}

自动探测不准确时，使用当前 Wi-Fi 下的局域网 IP，而非公网 IP。

  • macOS：执行 ipconfig getifaddr en0。Wi-Fi 通常为 en0，网线或热点可能为 en1；也可查看「系统设置 → 网络 → 当前连接 → 详细信息 → TCP/IP」。
  • Windows：执行 ipconfig，查看当前网卡的「IPv4 地址」。

局域网 IP 通常类似 192.168.x.x 或 10.x.x.x。

常见问题

mitm.it 打不开{{ disclosure_icon() }}

先验证步骤 0。无法连接电脑时，检查 Wi-Fi 隔离、IP 和网段；连通后再检查代理是否为手动、IP 和端口是否正确。地址必须为 http://mitm.it，不能使用 https。

手机打不开任何网页{{ disclosure_icon() }}

先关闭手机代理，确认能正常上网。再检查代理 IP 和端口、mock-server 是否运行，以及防火墙是否允许 {{ proxy_port }} 入站，然后重做步骤 0。

HTTP 正常，HTTPS 报错{{ disclosure_icon() }}

根证书未安装或未被信任。重做步骤 2，安装到「CA 证书」，不要选择「VPN 和应用证书」。

浏览器能抓包，App 抓不到{{ disclosure_icon() }}

该 App 可能不信任用户证书，或启用了 SSL Pinning。按步骤 3 检查 App 的证书信任配置。

多个 IP 不知道选哪个{{ disclosure_icon() }}

从默认网卡开始，用步骤 0 逐个验证上方的候选 IP。仍然无法连通时，让电脑连接手机热点，再重新查看 IP。

电脑 IP 经常变化{{ disclosure_icon() }}

为电脑配置静态 IP，或在路由器后台按 MAC 地址绑定固定 IP。
