Android

设置 Wi-Fi 代理，安装 CA 证书，再配置测试 App 的证书信任。

步骤 1 · 设置 Wi-Fi 代理{{ disclosure_icon() }}
  1. 进入手机「设置 → Wi-Fi」，打开当前网络的详情或「修改网络」。
  2. 展开「高级选项」，将「代理」设为手动。
  3. 主机名填写步骤 0 中已验证可连接的 IP，端口填 {{ proxy_port }}，保存。

MIUI/HyperOS、ColorOS、OneUI 的入口不同，可在 Wi-Fi 详情中搜索「代理」。

步骤 2 · 安装 HTTPS 证书{{ disclosure_icon() }}
  1. 在通用步骤 2 的证书下载页选择 Android，下载 mitmproxy-ca-cert.cer。
  2. 进入「设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书」，选择下载的文件，命名并保存。

不同系统的入口名称可能不同。选择「CA 证书」，不要选择「VPN 和应用证书」。

步骤 3 · 配置 App 的 HTTPS 信任{{ disclosure_icon() }}

面向 Android 7+ 的 App 默认不信任用户安装的 CA。浏览器可以抓包，但 App 通常还需要配置证书信任：

  • App 声明信任用户证书：在 network_security_config.xml 的信任配置中加入 <certificates src="user"/>，并确保 Manifest 引用该配置；建议仅用于 debug 构建，重新打包安装。
  • 系统证书：在具备 root 权限的测试设备或模拟器上安装为系统 CA。旧版常见路径为 /system/etc/security/cacerts/，新版安装方式可能不同。

如果 App 启用了 SSL Pinning（证书绑定）或自定义证书校验，还需要调整测试版本中的校验；仅信任用户 CA 不足以绕过证书绑定。已有测试流程也可使用 frida / objection 调整运行时校验。
